# 3D पेपर एनिमेशन वीडियो क्रिएटर

**रंगीन 3D पेपर कटआउट एनिमेशन वीडियो बनाएं - केवल आपके एंड्रॉइड फोन पर!**

## ✨ विशेषताएं

- 🎨 **हिंदी यूजर इंटरफेस** - पूरी तरह से हिंदी में
- 📝 **कहानी/विषय इनपुट** - अपनी कहानी लिखें या शैक्षिक विषय दें
- ✂️ **ऑटोमैटिक सीन डिवीजन** - कहानी अपने आप सीन में बंट जाती है
- 🎭 **3D पेपर कटआउट** - रंगीन लेयर्ड पेपर कटआउट पात्र और पृष्ठभूमि
- 🎬 **एनिमेशन** - चलते पात्र, कैमरा मूवमेंट, सीन ट्रांजिशन
- 📜 **हिंदी सबटाइटल** - 3D टेक्स्ट स्प्राइट के रूप में
- 🔊 **हिंदी वॉयस नरेशन** - वेब स्पीच API (फ्री, ऑफलाइन काम करता है)
- 🎵 **बैकग्राउंड म्यूजिक** - प्रोसीजरल जेनरेटेड एंबिएंट म्यूजिक
- 📹 **वीडियो प्रीव्यू और एक्सपोर्ट** - WebM/MP4 में रेंडर करें
- 📱 **मोबाइल-फर्स्ट** - एंड्रॉइड ब्राउज़र के लिए पूरी तरह रिस्पॉन्सिव
- 💰 **पूरी तरह फ्री** - कोई पेड API, कोई क्रेडिट कार्ड नहीं
- 🔧 **ओपन सोर्स टूल्स** - Three.js, Web Speech API, MediaRecorder API

## 🚀 उपयोग कैसे करें

### 1. ऐप चलाएं
```bash
# सरल HTTP सर्वर शुरू करें
cd /workspace/app
python3 -m http.server 8080
# या Node.js के साथ
npx http-server -p 8080
```

फिर ब्राउज़र में खोलें: `http://localhost:8080`

### 2. Android फोन पर उपयोग करें
- फोन के ब्राउज़र (Chrome/Firefox) में URL खोलें
- "होम स्क्रीन पर जोड़ें" से PWA के रूप में इंस्टॉल करें
- ऑफलाइन भी काम करता है (Service Worker के साथ)

### 3. वीडियो बनाने के चरण

#### चरण 1: कहानी लिखें
- अपनी कहानी या शैक्षिक विषय हिंदी में लिखें
- कम से कम ५० अक्षर लिखें
- सेटिंग्स चुनें: स्टाइल, रंग थीम, आस्पेक्ट रेश्यो, सीन अवधि
- "सीन बनाएं" दबाएं

#### चरण 2: सीन संपादित करें
- हर सीन की कहानी, पात्र, पृष्ठभूमि देखें
- किसी सीन पर टैप करके संपादित करें
- AI से पुनः बनाने के लिए "पुनः बनाएं" दबाएं
- "एनिमेशन बनाएं" दबाएं

#### चरण 3: एनिमेशन देखें
- प्ले/पॉज बटन से एनिमेशन चलाएं
- टाइमलाइन पर टैप करके सीक करें
- सेटिंग्स एडजस्ट करें: गति, कैमरा, ट्रांजिशन, पेपर मोटाई
- फुलस्क्रीन मोड उपलब्ध
- "वीडियो एक्सपोर्ट करें" दबाएं

#### चरण 4: वीडियो एक्सपोर्ट
- रिज़ॉल्यूशन चुनें: 720p (तेज़), 1080p (HD), 4K (धीमा)
- फ्रेम रेट: 30 या 60 FPS
- फॉर्मेट: WebM (VP9) या MP4 (H.264)
- "रेंडर शुरू करें" दबाएं
- प्रोग्रेस बार देखें
- तैयार होने पर डाउनलोड या शेयर करें

## 🎯 उपयोग के उदाहरण

### शैक्षिक वीडियो
```
विषय: "पानी का चक्र समझाएं"
```
ऑटोमैटिकली बनेगा: वाष्पीकरण, संघनन, वर्षा, संग्रह के सीन

### कहानी वीडियो
```
कहानी: "एक छोटा खरगोश जंगल में रहता था। उसे गाजर बहुत पसंद थी। एक दिन वह गाजर ढूंढते हुए एक नदी के पास पहुँचा..."
```
बनेगा: खरगोश पात्र, जंगल पृष्ठभूमि, नदी सीन के साथ

## ⚙️ तकनीकी विवरण

### उपयोग की गई टेक्नोलॉजी
- **Three.js** - 3D रेंडरिंग (ES Modules via CDN)
- **Web Speech API** - हिंदी TTS (ब्राउज़र बिल्ट-इन)
- **Web Audio API** - साउंड इफेक्ट्स और म्यूजिक
- **MediaRecorder API** - वीडियो रिकॉर्डिंग
- **Canvas API** - सबटाइटल रेंडरिंग
- **Service Worker** - ऑफलाइन सपोर्ट
- **PWA Manifest** - इंस्टॉल करने योग्य ऐप

### ब्राउज़र सपोर्ट
- ✅ Chrome 80+ (Android/Desktop)
- ✅ Firefox 75+ (Android/Desktop)
- ✅ Edge 80+
- ✅ Safari 14+ (iOS/macOS)
- ⚠️ MP4 एक्सपोर्ट के लिए MediaRecorder H.264 सपोर्ट चाहिए

### परफॉर्मेंस टिप्स
- 720p 30fps मोबाइल के लिए सबसे तेज़
- 10+ सीन से बचें (मैक्स 10 सीन)
- एक्सपोर्ट के दौरान ऐप को बैकग्राउंड में न भेजें
- बड़ी वीडियो के लिए डेस्कटॉप ब्राउज़र बेहतर
